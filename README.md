# Bring Me The Horizon // Cathedral Live Photography Portfolio ✠

A dark, atmospheric, gothic and medieval-styled concert photography web portfolio dedicated to the cathedral visuals and live aesthetic of Bring Me The Horizon.

## Features
- **Gothic & Medieval Cathedral Aesthetics**: Pointed arches, sacred geometry, liturgical typography (*Cinzel Decorative*, *UnifrakturMaguntia*), and deep crimson/gold lighting.
- **Interactive Lightbox Modal**: High-definition inspection of concert relics with keyboard navigation (`Left`, `Right`, `Escape`).
- **Full Resolution Raw Access**: Visitors can inspect and download the raw 4K / UHD concert shots.
- **Synthesized Ambient Drone**: Web Audio API cathedral drone and pipe-organ acoustics with real-time lowpass filter and reverb emulation.
- **Dust & Atmospheric Particle System**: Simulates liturgical smoke and floating dust in cathedral light rays.
- **Performance Optimized**: Dual-tier image pipeline (high-performance responsive previews + lossless original photos).

## Deployment to Vercel

### Option 1: Via Vercel CLI
```bash
npm i -g vercel
vercel
```

### Option 2: Via GitHub Integration
1. Push this repository to your GitHub profile.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Select your GitHub repository.
4. Framework Preset: **Other** (Static HTML).
5. Click **Deploy**.
